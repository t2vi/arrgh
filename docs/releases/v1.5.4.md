# *ARRgh v1.5.4: Release images build from bare version tags

**Released**: 2026-10-23

**Version level: PATCH.** A CI-only hotfix. The app is identical to v1.5.3, and nothing changes
for Docker/Kubernetes installs beyond the image tag.

---

## Highlights

- **Release images build again.** The GHCR workflow only ran on `v*` tags, but gitflow releases
  are tagged bare (`1.5.3`), so v1.5.3 shipped with no `ghcr.io/t2vi/arrgh:1.5.3` image. Pulling
  it failed with `not found` (`ImagePullBackOff` on Kubernetes).

---

## What's fixed

### GHCR workflow trigger (PR #271)

- `.github/workflows/ghcr.yml` now triggers on bare `X.Y.Z` tags as well as `v*`. That covers
  both the `arrgh` and `plugin-host` images, which share the trigger.
- The missing v1.5.3 images were built after the fact from a `v1.5.3` tag on the same commit
  (`110f657`). That tag is redundant from this release on.

---

## Spec coverage

Unchanged from v1.5.3 (CI workflow only, no code surface touched).

---

## Upgrading

```bash
docker compose pull
docker compose up -d
```

- **No migrations, no new settings.** Pin `1.5.4` (or keep `1.5.3`, now that its image exists;
  the app code is the same).
