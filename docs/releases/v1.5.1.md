# *ARRgh v1.5.1: Discover source-fallback search

**Released**: 2026-09-29

**Version level: PATCH.** Discover gains a fallback path so a title a configured source has but no
metadata authority catalogs is still findable — closing a real search gap (#254) rather than
adding a new user-facing capability of its own. No breaking API or config changes, and no new
migrations.

---

## Highlights

- **A title only a source has is now findable (GH #254).** Discover normally only searches
  MangaUpdates, AniList, MangaDex, NovelUpdates, WuxiaWorld, Royal Road, and nhentai — never a
  chapter source (novelfull, novelfullnet, toonily, ...) directly. When every authority for a
  content type returns nothing, Discover now falls back to querying that content type's own
  configured sources and shows what they find, marked distinctly ("Found via source") since their
  metadata is typically thinner than an authority's.

---

## What's new

### Discover source-fallback search (GH #254)

- Triggers only when the merged authority results for a content type are fully empty — a content
  type an authority already answered never queries a source, so ordinary searches see no added
  cost.
- Reuses the exact same source list, priority, and enabled/hentai-visibility rules an admin already
  manages via Settings → Sources (the same lookup post-add source matching uses) — no new
  configuration surface.
- A slow, unreachable, or erroring source contributes nothing and never blocks the rest of the
  search — the same soft-fail behavior post-add source matching already relies on.
- A source-fallback result adds to the library through the exact same flow as any other Discover
  result.

**Known follow-up (GH #255)**: Royal Road's own search returns loosely-relevant results for
queries containing common words, so "novel" search rarely registers as fully authority-empty in
practice — the two titles originally reported in #254 won't visibly surface until #255 is fixed.
The mechanism itself is verified working (proven live against a content type where an authority
genuinely returned zero results).
