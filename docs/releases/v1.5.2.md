# *ARRgh v1.5.2: Discover source-fallback actually works now

**Released**: 2026-09-29

**Version level: PATCH.** Fixes v1.5.1's source-fallback search (#254) and a misleading UI state it
exposed — both corrections to already-shipped behavior, no new capability.

---

## Highlights

- **Source-fallback (#254) never actually ran in the browser.** v1.5.1 wired it into
  `GET /api/discover`, but the web UI calls `GET /api/discover/stream` exclusively — so the fix
  looked shipped but a search from the actual app never triggered it. Fixed.
- **Royal Road's loose search relevance (#255)** — the reason the two originally-reported titles
  ("A Dragon against the Whole World", "I Have a Task Log") never surfaced — shipped separately
  as `arrgh-plugin-royalroad` v1.0.1. Both titles are now confirmed findable end-to-end, via the
  `novelfullnet` source.
- **Discover no longer shows a "finished-looking" partial result mid-search.** Results now render
  only once the entire search (every authority + source-fallback) has settled; a spinner next to
  "Searching sources…" makes the wait visible in the meantime.

---

## What's fixed

### Discover source-fallback now runs on the endpoint the app actually uses (#254)

- `search_stream()` (`server/src/api/discover.rs`) now calls the same `source_fallback_results`
  the one-shot endpoint already used, emitting one extra `source`-shaped event
  (`key: "source_fallback"`) before `done`.
- Added an integration test targeting `/api/discover/stream` specifically — every prior
  source-fallback test only covered the one-shot endpoint, so this gap had no test to catch it.

### Discover UI no longer flashes an incomplete result set (spec 021, amended)

- `web-svelte/src/lib/discover.svelte.ts` now buffers stream results and only commits them once
  the stream's `done` event fires — the per-source progress pills still update live, but the
  result list itself waits for the whole search, including source-fallback, to settle.
- A spinner now sits next to "Searching sources…" (`SearchProgress.svelte`), driven by overall
  fetch state rather than just the seven authority pills, since source-fallback has no pill of
  its own and used to make the header say "done" before it had actually finished.
- Spec 021's FR-008, User Story 2, and SC-001 were amended to describe this corrected contract —
  the original spec called for incremental reveal, which this release deliberately reverses. See
  `specs/021-discover-live-progress/spec.md`'s Amendments section.

### Royal Road plugin — search relevance filter (#255, shipped separately)

- `arrgh-plugin-royalroad` v1.0.1: Royal Road's own search matches loosely across
  description/tags for common-word queries. Results are now filtered to those whose title
  contains every significant (non-stopword) query word. Released independently
  (`t2vi/arrgh-plugin-royalroad` v1.0.1); `plugin-index/index.json` repinned to it ahead of this
  release.
