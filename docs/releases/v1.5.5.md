# *ARRgh v1.5.5: Scroll reader retries pages that fail to load

**Released**: 2026-10-25

**Version level: PATCH.** One reader bug fix. No new capability, API, setting or migration.

---

## Highlights

- **Pages no longer vanish in scroll mode.** A page that failed to load mid-chapter was treated
  as "past the end of the chapter" and silently dropped. The progress bar said halfway while the
  scrollbar sat at the bottom, and only toggling paged ↔ scroll brought the pages back.

---

## What's fixed

### Scroll reader drops failed pages (#274, PR #275)

- When the chapter's page count is known, a page that fails to load (e.g. the on-demand source
  proxy behind `/api/media/page` times out) keeps its slot. It retries automatically three
  times with backoff, then shows **"Page N failed to load · Retry"**.
- When the page count is unknown, a failure still marks the end of the chapter, as before.
- Spec `012-fix-scroll-reader` gained User Story 2 (FR-005, FR-006), unit-tested in
  `ScrollReader.svelte.test.ts`.

### Version string

- v1.5.4 was a CI-only hotfix that didn't bump `server/Cargo.toml`, so `GET /api/version` and
  the UI kept reporting `1.5.3`. They now report `1.5.5`.
