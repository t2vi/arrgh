*ARRgh v1.3.0: Auto-download works, settings that do what they say

Released: 2026-09-27

Version level: MINOR. One new capability ships: libraries now re-sync on a schedule and auto-download newly released chapters. Everything else is a fix, several of them to settings that were saved but had no effect. No breaking API or config changes, and no new migrations.

Highlights

  • Auto-download works. Every Sync interval (Settings, 1–24 h), library titles re-sync. New chapters are queued automatically when auto-download is on, either globally or per title (Global / Always / Never). Before this release, both toggles and the Sync interval did nothing.
  • Home → New releases shows new chapters. It was always empty: nothing ever marked a chapter as new, in any version of the app.
  • Settings that now take effect:
    • Library path overrides the DownloadDir env var (after a restart, as the UI says).
    • Trending titles per source sets how many cards each trending lane shows.
    • Download workers already worked (since v1.2.0) and is now specified and tested.
  • Title fixes:
    • Admins can set a title’s content type to hentai.
    • Changing a content type now re-matches sources, as the card always promised.
    • A title’s chapter list is only visible to users who have that title in their library.
  • The arrgh favicon is back in the browser tab. It had shown Vite’s default icon since the Svelte port.

What’s new

Scheduled re-sync + auto-download (GH #200)

A background job wakes every index_interval_hours (Settings → Sync interval, clamped 1–24, re-read every cycle; first run one interval after start-up). It re-syncs each library title through the same path as the manual Sync button, then queues the chapters that sync newly found when auto-download applies: the title’s own setting if set, otherwise the global one (default off). The existing backlog is never auto-queued. Auto-queued items show no user in the queue and can be cancelled by admins.

New releases (GH #210)

A chapter counts as a new release when a re-sync of a title that already had chapters finds it. Adding a title never floods the section: its first import isn’t “new”, and neither are chapters pulled in by Discover’s source matching. The section shows the 30 most recent.

Settings fixes (GH #203)

SettingBeforeNow
Library path (download_dir)Saved, but downloads and the cover cache only used the DownloadDir env varRead at start-up and overrides the env var; empty means use the env var. Per-title folders still win.
Trending titles per sourceIgnored; lanes always showed 6Each lane shows this many (default 5, 1–20 in the UI)
Download workersWorked since v1.2.0, but unspecifiedSpecified and tested (1–10 parallel downloads)

Title management fixes (GH #211)

  • The admin Content Type card offers all five types, hentai included.
  • Changing a title’s content type drops its links to sources that don’t serve the new type, then re-matches sources in the background.
  • GET /api/chapters/title/{id} returns not-found unless the title is in the caller’s library, the same rule as opening the title.

Also

  • Favicon (GH #205): the arrgh icon set, apple-touch icon, web manifest and theme colour are restored.
  • Code health (GH #161–#163): roles, download statuses, content types, chapter formats and sync statuses are shared constants; SQL binds them instead of inlining literals. No behaviour change.
  • Docs: “East Asian” is gone from the description and docs site. arrgh covers English-original web novels too.

Spec coverage

This is the first release with the spec-coverage ledger (/spec-audit release):

Spec coverage: 84% of surfaces (94/112, 0 unspecced), 74% of FRs have a test (18/257 at planned layer)

Since the post-v1.2.0 baseline, the last 5 unspecced surfaces (library and title management) are covered (retroactive spec 032). No surface added in this release is unspecced, and the untested-FR count did not rise.

Upgrading

docker compose pull
docker compose up -d
  • No migrations, no new env vars.
  • Auto-download starts working. If you’d turned it on (globally or per title), new chapters will be queued after the first Sync interval (default 6 h) following the upgrade. Titles are re-synced on that interval regardless of auto-download.
  • Library path: if you set one in Settings, it now takes effect. Check that it points inside your data volume (/data/downloads in the stock container) before restarting.
  • Trending lanes show 5 cards by default instead of 6. Change Trending titles per source to set your own.
