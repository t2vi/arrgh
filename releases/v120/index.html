*ARRgh v1.2.0: English-original novels, live Discover, source fixes

Released: 2026-09-27

Version level: MINOR. New capabilities ship: a new Discover authority and two sources (Royal Road, NovelFull.net), a streaming Discover endpoint, and a download-concurrency setting that finally works. There are no breaking API or config changes.

Highlights

  • English-original novels: Royal Road is now a Discover authority and a download source. Titles like The Primal Hunter can be found, added and read with no manual setup.
  • New source: NovelFull.net. It has a different catalog from NovelFull (novelfull.com) and carries full English-original novels such as The Primal Hunter.
  • Live Discover: each source’s results appear as soon as it answers, with per-source progress. A slow source no longer holds back the rest.
  • Source fixes:
    • MangaDex search works again
    • NovelUpdates search works again
    • nhentai is fast again
    • WuxiaWorld chapters are no longer blank
    • Royal Road covers and NovelUpdates synopses are back
  • Chapter numbering fix: lettered or unnumbered chapters no longer collapse into each other (e.g. Dungeon Crawler Carl showed only 5 of 100+ chapters).
  • Reliability:
    • A hung source can no longer stall a search, sync or download forever.
    • The Download workers setting now actually runs that many downloads at once.

What’s new

English-original novels via Royal Road (spec 019, ADR 0034)

The novel authorities (NovelUpdates, WuxiaWorld) only catalog translated Asian fiction. Royal Road is now the seventh Discover authority and a bundled Source (priority 35, ahead of NovelFull; no CloakBrowser needed).

  • Chapter numbers come from the chapter title, not list position, so “stub” fictions with removed chapters don’t mis-merge.
  • Royal Road’s hidden anti-piracy lines are stripped from chapter text.
  • Existing installs get the source row through migration 0004.

NovelFull.net source (spec 027, GH #189)

novelfull.net carries titles that novelfull.com doesn’t. It’s added as its own Source (novelfullnet, priority 45, CloakBrowser) through migration 0005, and loads full chapter lists through the site’s own paging (40 chapters per page).

Live Discover progress (spec 021)

  • Streaming endpoint: GET /api/discover/stream returns NDJSON. First comes the list of sources, then one event per source as it finishes (found / empty / error / timeout, with a count and timing), then a final done event.
  • UI: Discover renders results as they arrive and shows each source’s status.
  • Timeouts: every source is bounded by a shared 90 s limit, and the one-shot GET /api/discover uses the same bound.
  • No fake loading: cards with no synopsis no longer show a skeleton forever (spec 028, GH #191).

Chapter numbering and re-sync (spec 030, GH #195)

  • Lettered chapters (2.A) become 2.1.
  • An unnumbered chapter takes the previous number + 0.01.
  • A source with no numbers at all is numbered 1..n.
  • Re-sync moves a renumbered chapter instead of leaving a stale duplicate, and updates a chapter’s stored source link when the source reports a new one.

Reliability

  • Plugin call timeout (GH #159): plugin-host bounds every plugin call and answers 504 when it runs out of time. The limit is set with PLUGIN_CALL_TIMEOUT_MS (default 180000). Previously a stuck site request could hang a search, sync or download indefinitely.
  • download_workers works (GH #160): the downloader runs up to that many chapters in parallel (default 2, clamped 1–10). A change applies within one tick (3 s), with no restart.
  • Error logs name the endpoint: server failure log lines now include the request method and path (GH #188).

Developer experience

  • ./scripts/dev-up.sh builds the current plugins from the working tree (scripts/sync-plugins.sh) and points at the repo’s plugin index, so dev no longer runs stale bundles and Settings → Plugins no longer 502s (spec 020, GH #186).
  • plugin-host unloads a plugin when its bundle file is removed (GH #187).
  • plugin-host tests no longer fail with EADDRINUSE while the dev stack is running (spec 025, GH #183).

Upgrading

docker compose pull
docker compose up -d
  • Migrations 0004_restore_royalroad_source.sql and 0005_add_novelfullnet_source.sql run automatically on boot. They add the Royal Road and NovelFull.net sources to existing installs.
  • Downloads now run in parallel. If you never changed Download workers, it was always shown as 2 but ran 1 at a time; it now runs 2. Set it to 1 in Settings → Downloads to keep the old behaviour.
  • WuxiaWorld titles: re-sync them once to replace old guessed chapter links. Chapters behind WuxiaWorld’s Karma/VIP paywall are no longer listed from WuxiaWorld; another source may still cover them.
  • Known issue: the auto-download toggles (global and per title) and the Sync interval setting currently do nothing. New chapters appear only when you re-sync a title, and must be queued by hand (GH #200).
  • Titles with oddly numbered chapters (e.g. Dungeon Crawler Carl): re-sync to pick up the missing chapters.
